
# Лабораторная работа №4 — Unit-тестирование

## Описание проекта

Проект создан для изучения модульного тестирования на Python с использованием стандартной библиотеки `unittest`.

Программа вычисляет площадь и периметр прямоугольника, а также проверяет корректность входных данных.

Реализованы две функции:
- `area(a, b)` — вычисление площади прямоугольника.
- `perimeter(a, b)` — вычисление периметра прямоугольника.

Если длина хотя бы одной стороны отрицательная, вызывается исключение `ValueError`.

## Структура проекта

- `rectangle.py` — реализация функций вычисления площади и периметра.
- `test_rectangle.py` — 30 автоматизированных Unit-тестов.
- `.gitignore` — исключение служебных файлов Python из Git.

## Реализованные тесты

Всего реализовано 30 тест-кейсов, проверяющих:

1. Вычисление площади и периметра обычных прямоугольников.
2. Вычисление площади и периметра квадратов.
3. Работу с нулевыми значениями сторон.
4. Вычисления с дробными числами.
5. Обработку больших числовых значений.
6. Обработку отрицательных значений сторон.
7. Корректное возникновение исключения `ValueError`.
8. Точность вычислений с числами с плавающей точкой.

Для проверки используются методы:
- `assertEqual()` — сравнение результата с ожидаемым.
- `assertRaises()` — проверка возникновения исключения.
- `assertAlmostEqual()` — приближённое сравнение вещественных чисел.

## Запуск тестов

Для запуска необходим Python 3. Установка дополнительных библиотек не требуется.

Откройте терминал в папке проекта и выполните:

```bash
python3 -m unittest test_rectangle.py -v
```

В Windows можно использовать:

```bash
python -m unittest test_rectangle.py -v
```
