
# Лабораторная работа №4 — Unit-тестирование

## Описание проекта

Проект создан для изучения модульного тестирования на Python с использованием стандартной библиотеки `unittest`.

Программа вычисляет площадь и периметр прямоугольника и проверяет корректность входных данных.

## Структура проекта

- `rectangle.py` — функции вычисления площади и периметра прямоугольника.
- `test_rectangle.py` — модульные тесты для проверки функций.
- `.gitignore` — исключение служебных файлов Python из Git.

## Реализованные тесты

Всего реализовано 7 Unit-тестов, проверяющих:

1. Вычисление площади обычного прямоугольника.
2. Вычисление площади прямоугольника с нулевой стороной.
3. Вычисление периметра прямоугольника.
4. Вычисление площади квадрата.
5. Обработку отрицательной стороны при вычислении площади.
6. Вычисление площади с дробными сторонами.
7. Обработку отрицательной стороны при вычислении периметра.

## Запуск тестов

Откройте терминал в папке проекта и выполните:

```bash
python -m unittest test_rectangle.py -v
```

Для Linux/WSL:

```bash
python3 -m unittest test_rectangle.py -v
```

## Результаты

Все 7 Unit-тестов успешно пройдены.

Тестирование подтверждает корректность вычислений и обработки отрицательных значений.
